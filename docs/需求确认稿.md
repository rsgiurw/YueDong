# 需求确认稿（v2）—— 「悦动」安卓健身 APP

> v2 更新：根据您的补充需求，新增首次使用问卷、饮食建议页、5 标签页结构；体型判断改为 BMI 自动计算。已按 ArchPilot 流程归档。

## 1. 项目定义

「悦动」：中文原生安卓健身 APP（Kotlin + Jetpack Compose），通过首次问卷了解用户（性别、年龄、身高、当前/目标体重、每周运动量、健身目的），自动计算 BMI 与每日热量/营养素目标，推荐匹配的训练计划；用户跟随计划锻炼、每日打卡、写健身日记、记录体重趋势。

定位：**求职作品集**（目标岗位：安卓开发），代码规范、架构清晰、可面试演示。

## 2. 第一版目标（核心闭环）

**首次问卷 → 自动算出 BMI/热量目标并推荐计划 → 跟着计划每天训练打卡 → 日历看坚持记录 → 记体重看趋势 → "我的"页看目标进度。**

## 3. 需求理解与假设

### 您已确认
1. 目的：求职作品集，目标岗位安卓开发
2. 技术路线：原生安卓 Kotlin + Jetpack Compose
3. 首次问卷：性别、年龄、身高、当前体重、目标体重、运动量、健身目的（减肥/塑形/健康等）
4. 页面结构：计划、推荐饮食、日记、锻炼记录、个人信息 5 大板块 → 组织为底部 5 标签：今日 / 计划 / 饮食 / 记录 / 我的
5. 饮食深度：热量目标 + 三大营养素建议 + 通用饮食建议（不做食物数据库与饮食记录）
6. 体型判断：不用主观选项，用身高体重自动算 BMI 并给出分类
7. 界面语言中文；UI 简洁直观、淡蓝色主色
8. 数据本地存储（Room），无服务器、无账号
9. 第一版不做 AI 功能，架构预留扩展接口

### 仍不确定 → 已按合理假设处理
1. 训练内容偏好 → 内置计划同时覆盖居家与健身房两类场景（用户选择）
2. 注释风格 → 关键逻辑详细、常规代码简洁（方便学习与面试讲解）
3. 作品集侧重 → 稳定无 bug 与界面颜值兼顾，架构可讲解

### 其他合理假设
1. 单人使用；日记为每日一条（心情 + 一句话）
2. 体重记录以手动输入为主（30~300kg 合法范围校验）
3. 在 Windows 电脑用 Android Studio 开发，成品安装到自己的安卓手机
4. 用 ZCode 分阶段执行编码（提示词兼容 Claude Code / Cursor）

## 4. UI 语言与界面风格

- 语言：全中文（按钮、提示、空状态、错误文案均中文）
- 风格：Material 3，简洁清爽，大字体大按钮，卡片式布局
- 主色：淡蓝 #64B5F6，强调深蓝 #1E6BB8，背景浅白灰 #F7FAFC
- 结构：底部 5 标签——**今日**（今日训练+打卡+体重速记+日记）、**计划**（内置/自定义计划）、**饮食**（热量目标+营养素+建议）、**记录**（打卡日历+统计+体重趋势图）、**我的**（个人信息+目标进度+关于）
- 必备状态：空状态 / 加载中 / 错误提示，全中文文案

## 5. 复杂度判断

- 评级：**中高**（移动端 APP、本地数据库、历史记录、图表、问卷流程、热量计算）
- 控制手段：拆为 8 个小阶段开发，每阶段可独立运行验证；不做食物数据库、AI、云同步、通知。

## 6. V1 功能范围

### 第一版包含
1. 首次使用问卷（含输入校验）→ 自动计算 BMI / BMR / 每日热量与三大营养素目标
2. 计划推荐：按健身目的+运动量自动推荐内置计划，可手动切换
3. 内置 3 套计划（居家燃脂入门 / 健身房力量入门 / 居家健康活力）+ 自定义新建计划
4. 今日页：今日训练内容、一键打卡、体重速记、每日日记（心情+一句话）
5. 记录页：打卡日历、连续/累计天数统计、锻炼历史、体重折线趋势图
6. 我的页：个人信息的查看与修改、目标体重进度、关于页
7. 全面的空状态/加载/错误处理与输入校验

### 第一版不包含（后续预留）
1. AI 教练（预留 `PlanRecommender`/`AiCoachService` 接口位置）
2. 账号、云同步（Repository 层隔离数据源，将来可换）
3. 食物数据库与饮食记录
4. 训练提醒通知、动作视频、社区、数据导出

## 7. 技术栈

Kotlin + Jetpack Compose (Material 3) + Room + ViewModel + Navigation Compose + DataStore；架构 MVVM + Repository；纯逻辑（BMI/热量/连击计算）独立成纯 Kotlin 模块并配单元测试。

## 8. 数据安全

身高体重等健康数据仅存手机本地，不上传任何服务器。

## 9. 下一步

生成《AI 编程项目 LLM 开发设计包》+《分阶段编码提示词》，然后从阶段 0（环境搭建）开始开发。
